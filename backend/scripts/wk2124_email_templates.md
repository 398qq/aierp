## 六、群发（5+ 客户）注意事项

1. **不要**用 "Dear Customer" / "尊敬的客户" —— 必须用 {{contact_name}}
2. **不要**抄送 5+ 客户的邮件——会被 Gmail/QQ/网易识别为垃圾邮件
3. **不要**首次邮件直接 PDF 附件——用云盘链接（百度网盘 / 飞书云文档 / 公司官网）
4. **必须**有明确 CTA（Call to Action）："10 分钟电话" / "样片申请" / "Demo Code"
5. **不要**承诺规格书没写的参数
6. **要**配 {{你的签名档}}：公司 logo + 电话 + 微信 + 官网

## 七、样片申请流程

**内部流程**（销售员需要做的）：
1. 客户回复"要样片" → 索要：联系人 / 公司 / 项目名称 / 用途 / 预计年用量
2. 填《样片申请单》（内部表单），提交技术 + 商务审核
3. 审批通过 → 仓库发货 5pcs（标准量）+ 1 份规格书 + 1 张名片
4. 快递发出后 → 当天发邮件/微信告知"样片已寄，单号 XXX"
5. 1 周后跟进："样片收到了吗？测试进展如何？"
6. 2 周后：客户没用 → 了解原因，记入 CRM（lead.notes 字段）
7. 客户在用 → 谈 BOM 价格 / 量产

## 八、关键 KPI（自己用）

- 邮件回复率：目标 ≥ 15%
- 样片申请转化：目标 ≥ 30%（发出 10 家，至少 3 家要用）
- 样片 → 设计验证：目标 ≥ 50%
- 设计验证 → 量产订单：目标 ≥ 30%
- 单 lead 转化周期：目标 ≤ 60 天

## 九、leads 表使用建议

```
查优先级:  SELECT * FROM leads WHERE product_id = 16 AND priority = 'high' ORDER BY fit_score DESC;
查今日待跟进:  SELECT * FROM leads WHERE product_id = 16 AND next_action_at::date = CURRENT_DATE;
按来源:  SELECT source, count(*) FROM leads WHERE product_id = 16 GROUP BY source;
查已转化:  SELECT * FROM leads WHERE product_id = 16 AND status = 'converted';
```

每条 lead 状态更新：
- `new` → `researching` → `contacted` → `qualified` → `converted` / `lost`
- 每次联系后更新 `last_contacted_at` + `next_action_at` + `next_action` 字段
- 转化后填 `converted_customer_id` 关联到 customers 表
